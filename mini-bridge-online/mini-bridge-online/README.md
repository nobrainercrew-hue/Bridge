# 미니 브릿지 온라인

친구와 함께 하는 미니 브릿지 웹 게임입니다. 방을 만들고 링크를 보내면 친구가 빈 자리에 앉고, 남은 자리는 AI가 채웁니다.

## 게임 방식

- 4자리(북·동·남·서), 북-남 / 동-서가 한 팀
- 사람 1~4명 + 나머지 AI
- 각자 **자기 카드만** 볼 수 있어요. 더미 카드도 공개하지 않고 AI가 대신 냅니다.
- 접속이 끊기면 그 자리는 AI가 대신 두고, 같은 기기·브라우저로 다시 들어오면 자리로 돌아옵니다.
- 패 정보는 서버에만 있고, 각 사람에게는 자기 카드만 전송됩니다.

## 내 컴퓨터에서 실행

Node.js 18 이상이 필요합니다.

```bash
npm install
npm start
```

브라우저에서 http://localhost:3000 을 엽니다. 같은 와이파이의 친구는 `http://<내 컴퓨터 IP>:3000` 으로 들어올 수 있어요.

## 웹에 올리기 (Render 예시, 무료)

1. 이 폴더를 GitHub 저장소로 올립니다.
2. https://render.com 에서 **New → Web Service** → 저장소 선택
3. 설정
   - Runtime: Node
   - Build Command: `npm install`
   - Start Command: `npm start`
4. 배포가 끝나면 `https://<이름>.onrender.com` 주소가 생깁니다. 이 주소를 친구에게 보내면 됩니다.

참고: Render 무료 플랜은 15분 정도 아무도 접속하지 않으면 서버가 잠들어서, 다음 접속 때 30초~1분 정도 늦게 열립니다. 서버가 재시작되면 진행 중인 방은 사라집니다.

Railway, Fly.io, 개인 서버(VPS)에서도 `npm install && npm start` 로 똑같이 돌아갑니다. 포트는 환경변수 `PORT` 를 따릅니다. 웹소켓(Socket.IO)을 쓰므로 nginx 같은 프록시 뒤에 둘 때는 WebSocket 업그레이드를 허용해야 합니다.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `server.js` | 방 만들기·참여, 자리, 진행 타이머, AI 대행, 플레이어별 화면 정보 |
| `game.js` | 규칙(딜, 점수 발표, 계약, 트릭, 점수 계산)과 AI |
| `public/index.html` | 웹 화면 |
| `test/play-through.js` | 2명이 접속해 두 판을 끝까지 두는 자동 테스트 (`npm test`) |

진행 속도는 `server.js` 위쪽의 `DELAY` 값(밀리초)으로 조절할 수 있습니다.
